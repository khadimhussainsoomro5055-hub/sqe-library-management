|---|---|---|---|---|---|---|---|---|---|
| TC-001 | Add a valid new book | REQ-1 | The library is available and the book ID does not already exist. | 1. | TC-002 | Reject duplicate book ID | REQ-2 | The library already contains a book with ID 101. | 1. Create another book with ID 101. 2. | TC-003 | Reject malformed book ID | REQ-2 | The system is ready to add a new book. | 1. Enter an invalid book ID such as "ABC". 2. | TC-006 | Return a book currently on loan | REQ-6 | Book 101 is issued to member Ali. | 1. Return book 101 for member Ali. 2. | TC-008 | Member borrows at allowed limit | REQ-4 | A member is allowed to borrow up to the defined borrowing limit and has not reached it. | 1. | TC-009 | Member attempts to exceed borrowing limit | REQ-4 | A member has already reached the allowed borrowing limit. | 1. Attempt to issue one additional available book to the member. 2. | TC-010 | Calculate fine for zero days overdue | REQ-6 | A returned book has zero overdue days. | 1. Calculate the fine for 0 overdue days. 2. | TC-011 | Calculate fine for mid-range overdue period | REQ-6 | A book is overdue by a number of days within a normal fine range. | 1. Enter a mid-range overdue period such as 5 days. 2. | TC-012 | Calculate fine at overdue-tier boundary | REQ-6 | The system has defined fine tiers with a boundary between two rates. | 1. Enter the exact number of overdue days at the tier boundary. 2. | TC-013 | Reject negative book quantity | REQ-3 | The system is ready to add a new book. | 1. Create a book with ID 106 and quantity -5. 2.
