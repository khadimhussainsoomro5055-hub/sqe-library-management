# Functional Requirements

## REQ-1
The system shall allow a new book to be added to the library.

## REQ-2
The system shall reject a book with a duplicate book ID.

## REQ-3
The system shall reject a book with a negative quantity.

## REQ-4
The system shall allow an available book to be issued to a member.

## REQ-5
The system shall prevent a book from being issued when no copies are available.

## REQ-6
The system shall allow an issued book to be returned.

## REQ-7
The system shall allow users to search for a book by its name.

## REQ-8
The system shall display the book ID, name, author, and available quantity.
